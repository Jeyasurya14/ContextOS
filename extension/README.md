# ContextOS Copilot

The AI Copilot that knows everything about your workspace.

ContextOS Copilot is a VS Code extension that connects directly to your ContextOS agent. It allows you to query your entire company's centralized knowledge base—including GitHub repositories, Slack conversations, Notion documents, Linear issues, and Google Drive files—directly from your editor.

## Features

- **Ask ContextOS**: Have a conversation with your customized AI assistant without ever leaving VS Code.
- **Context-Aware Insights**: Instantly receive answers that are firmly rooted in your team's live data sources.
- **Direct Code Referencing**: Highlight snippets of code and ask ContextOS to explain them or find relevant internal documentation.

## Setup

1. Open the VS Code Command Palette (`Cmd+Shift+P` on Mac, `Ctrl+Shift+P` on Windows/Linux).
2. Run the command **`ContextOS: Set API Key`**.
3. Enter your ContextOS API Key (you can generate this from your ContextOS dashboard settings).

## Requirements

- A [ContextOS](https://contextos.learnmade.in/) account.
- The extension requires VS Code 1.85.0 or higher.

## Privacy

ContextOS only uses your data to provide you with insights through your own private vector database. Your queries within the IDE are secured.
