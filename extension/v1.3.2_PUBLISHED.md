# ✅ v1.3.2 Published - Correct Fix Applied

## The Problem with v1.3.1

v1.3.1 had the bug because `\\x60` was being **double-escaped** by esbuild:
```javascript
// What we wrote:
text=text.replace(/\\x60([^\\x60]+)\\x60/g,'<code>$1</code>');

// What esbuild bundled (broken):
text=text.replace(/\\x60([^\\x60]+)\\x60/g,'<code>$1</code>');
// The backslashes were preserved, not interpreted as hex escape
```

## The Fix in v1.3.2

Used **single backslash** `\x60` (same as line 568 for fenced code blocks):
```javascript
// Correct fix:
text=text.replace(/\x60([^\x60]+)\x60/g,'<code>$1</code>');

// This bundles correctly to:
text=text.replace(/\x60([^\x60]+)\x60/g,'<code>$1</code>');
// Hex escape is properly interpreted
```
